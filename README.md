# CaixaUp

Sistema de frente de caixa simples para pequenos negócios.

## Instalação

Baixe sempre a versão mais recente em [Releases](https://github.com/thalleseduardo1450-bot/CaixaUp/releases/latest).

O aplicativo verifica, baixa e instala novas versões automaticamente. Novas versões só são publicadas manualmente quando solicitado.

## Código-fonte

O pacote-fonte de cada versão fica disponível neste repositório sem arquivos de ambiente, senhas ou dados locais.
